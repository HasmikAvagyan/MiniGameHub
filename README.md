# Տորք Անգեղ

A 2-player local arcade hub built in Unity, featuring four fully playable mini-games under one launcher. Players launch the hub and jump between games from a single main menu.

---

## Games

| Game | Description |
|------|-------------|
| Chess | Classic 2-player strategy board game |
| Glowing Pong | A neon-styled take on the arcade classic |
| Tic Tac Toe | Fast-paced 2-player X and O |
| Breakout | Ball and paddle brick-breaking action |

---

## How to Run

1. Download and extract the release zip
2. Open BuildOutput/Build/MiniGameHub.exe
3. Click any game icon from the main menu to launch it
4. Press the Quit button inside a game to return to the main menu

> Make sure all game folders stay next to MiniGameHub.exe — do not move individual .exe files out of their folders.
